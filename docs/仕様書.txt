# Place Matrix v2
# iPhone Location Information Visualization App

あなたは経験豊富なiOSエンジニアです。

Claude Codeを使用して、SwiftUIベースのiPhoneアプリ
「Place Matrix」を段階的に開発してください。

このアプリは、地図上の場所に情報を登録し、
その情報を「単一情報表示」または「4分割インジケータ」として
視覚的に表示することを目的とします。

==================================================
## 1. アプリのコンセプト
==================================================

場所に紐づく情報を登録する。

例:

A市

・電気
・水道
・ガス
・通信

または

A市

・火災
・浸水
・倒壊
・その他

登録した情報を地図上に表示する。

表示方法は2種類。

### 単一情報表示

1つの情報を1つのインジケータとして表示する。

例:

┌────────┐
│   ⚡   │
│  電気  │
│  🟢   │
│ 正常   │
└────────┘

### 4分割インジケータ

1つの場所について4つの情報を、
1つの正方形を4分割して表示する。

例:

┌────────┬────────┐
│   💧   │   📡   │
│  水道  │  通信  │
│  🟢   │  🟠   │
├────────┼────────┤
│   ⚡   │   🔥   │
│  電気  │  ガス  │
│  🟡   │  🔴   │
└────────┴────────┘

4分割の各区画は独立した情報を表す。

==================================================
## 3. 情報モデル
==================================================

情報には以下の概念を持たせる。

Place
    地理的な場所

Information
    Placeに紐づく情報

Informationは、

- name
- icon
- level
- levelName
- memo
- updatedAt

を持つ。

levelは数値で管理する。

MVPでは:

0 = 不明
1 = 正常
2 = 注意
3 = 警戒
4 = 危険

とする。

ただし将来的にレベル名称と色を
ユーザーが変更できる構造を考慮する。

==================================================
## 4. 重要な設計思想
==================================================

「4分割」は4つの固定フィールドではない。

4つのInformationを、
表示位置を指定して配置する。

Position:

- topLeft
- topRight
- bottomLeft
- bottomRight

したがって、

Place
  └─ Information × N

という構造にする。

4分割表示を使用する場合は、
4つのInformationを指定された位置に配置する。

単一情報表示の場合は、
Informationを1つだけ表示する。

- 病院

- 救急
- その他

Traffic

- 鉄道
- 道路
- バス
- その他

Templateによって、

「どの4情報を4分割表示するか」

を決定する。

==================================================
## 6. ピクトグラム
==================================================

MVPではSF Symbolsを優先する。

例:

電気:
bolt.fill

水道:
drop.fill

ガス:
flame.fill

通信:
antenna.radiowaves.left.and.right

火災:
flame.fill

浸水:
water.waves

倒壊:
house.fill

その他:
exclamationmark.triangle.fill

ただし、SF Symbolsに存在しない場合は
適切な代替アイコンを使用する。

InformationはiconNameを文字列として保持し、
表示時にSF Symbolsへ変換する。

==================================================
## 7. 色
==================================================

色はInformationの意味ではなく、
「状態レベル」を表す。

デフォルト:

Level 0:
gray

Level 1:
green

Level 2:
yellow

Level 3:
orange

Level 4:
red

色とレベルは将来的に変更可能な設計にする。

色だけに依存せず、

- icon
- levelName
- 色

の3つで状態を認識できるUIにする。

==================================================
## 8. 地図
==================================================

MapKitを使用する。

地図上にはPlaceを表示する。

Placeの表示方法:

### 単一情報

1つのInformationを表示。

### 4分割

1つの正方形を4分割した
FourQuadrantIndicatorを表示。

地図上のAnnotationに
カスタムSwiftUI Viewを使用できる設計にする。

==================================================
## 9. 4分割インジケータ
==================================================

MVPでは「正方形4分割」を正式仕様とする。

菱形表示は将来のデザイン候補として残す。

基本UI:

┌────────┬────────┐
│        │        │
│   A    │   B    │
│        │        │
├────────┼────────┤
│        │        │
│   C    │   D    │
│        │        │
└────────┴────────┘

各区画には、

- icon
- shortName
- levelColor

を表示する。

小さい表示では、

icon + color

だけに簡略化してよい。

└──────────┘

Medium:

## 17. 開発ルール
==================================================

- 小さな単位で実装する
- 実装前に変更内容を説明する
- 勝手に次のPhaseへ進まない
- 各Phase終了時にビルドする
- コンパイルエラーを残さない
- ViewからDBを直接操作しない
- Repositoryを使用する
- 位置情報処理をViewから分離する
- 外部ライブラリを勝手に追加しない
- 不要な抽象化を避ける
- SwiftUIの標準機能を優先する
- 初心者でも理解できるコードを優先する

## 18. MVPのゴール
==================================================

最終的に以下が動作すればMVP完成とする。

1.
地図上で現在地を取得できる。

2.
場所を登録できる。

3.
PlaceにTemplateを設定できる。

4.
Templateに応じてInformationを4つ登録できる。

5.
各Informationに、

- ピクトグラム
- Level
- LevelName
- Memo

を設定できる。

6.
Placeを地図上に表示できる。

7.
4分割インジケータで、

icon + 色

を表示できる。

8.
単一Informationを
SingleInformationIndicatorとして表示できる。

9.
Placeをタップすると詳細を表示できる。

10.
SQLiteに保存され、
アプリ再起動後もデータが残る。

11.
データを編集・削除できる。

12.
基本的な検索・一覧表示ができる。
